# Code with Mureithi: Astro port

This workspace contains the first Astro parity slice for the public site at
[mureithi.me](https://mureithi.me/).

## Run

    pnpm install
    pnpm dev

Open the representative post at
/blog/background-job-processing-with-rust-actix-redis.

The source MDX and author record are in src/content/. The project uses Tailwind
CSS 4.3.0.

See [MIGRATION_STATUS.md](./MIGRATION_STATUS.md) for audited behavior, current
parity gaps, and the Astro runtime decision.
